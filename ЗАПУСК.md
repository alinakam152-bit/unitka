# Как запустить Юнитку на настоящих данных

Всё ниже делаешь ты сама: это ключи, пароли и твой аккаунт GitHub. Ключи никому не присылай, в том числе мне в чат.

## 1. Придумай фразу-расшифровку

4–5 случайных слов через пробел, например «чайник ветер пятница облако компас» (эту не бери). Запиши её туда, где хранишь пароли. Без неё цифры не открыть, восстановить её нельзя.

## 2. Ключи площадок (только чтение)

**WB, магазин «комильфо».** ЛК WB → Настройки → Доступ к API → «Создать новый токен». Тип: «Только на чтение». Галочки:
Контент, Статистика, **Аналитика**, Продвижение, Цены и скидки, Маркетплейс, Финансы.
Сейчас у ключа нет «Аналитики», поэтому остатки на складах WB не приходят.

**Ozon, магазины «for you», «малиноф», «мангустин».** Для каждого магазина: ЛК Ozon → Настройки → Seller API → «Сгенерировать ключ», роль «Администратор только для чтения» (Admin read only). Понадобятся Client ID и сам ключ.

⚠️ Ключ «for you» в LiteStat истекает 02.12.2026 — заодно продли его там.

## 3. Репозиторий на GitHub

1. github.com → New repository → имя `unitka` → **Public** (бесплатный GitHub Pages работает только с публичными) → Create.
2. Загрузи в него содержимое папки `Приложения/unitka` (могу сделать я: войди в GitHub CLI командой `gh auth login` в терминале и скажи мне «загружай»).

## 4. Сейф репозитория (Secrets)

Репозиторий → Settings → Secrets and variables → Actions → New repository secret. Названия — ровно такие:

| Название | Что вставить |
|---|---|
| `UNITKA_PHRASE` | фраза-расшифровка из шага 1 |
| `WB_KOMILFO_TOKEN` | токен WB «комильфо» |
| `OZON_FORYOU_CLIENT_ID` / `OZON_FORYOU_API_KEY` | Client ID и ключ «for you» |
| `OZON_MALINOF_CLIENT_ID` / `OZON_MALINOF_API_KEY` | то же для «малиноф» |
| `OZON_MANGUSTIN_CLIENT_ID` / `OZON_MANGUSTIN_API_KEY` | то же для «мангустин» |

## 5. Включить сайт и робота

1. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
2. Actions → «Обновить данные» → Run workflow. Первый запуск идёт 20–40 минут: WB разрешает один запрос в минуту.
3. Дальше робот запускается сам каждый день в 05:00 по Екатеринбургу.

## 6. Проверка

Открой ссылку `https://<твой-логин>.github.io/unitka/` на телефоне, введи фразу → должны быть видны 4 магазина.
В другом браузере без фразы цифр видно быть не должно.
